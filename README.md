# Periodic Table Trainer

A single-page site for learning the elements of the periodic table in chunks:
first 5, first 10, first 20, then all 118.

- **Table**: colour-coded periodic table, tap any element for details
- **Learn**: flashcards with hide-names / hide-symbols
- **Quiz**: number → symbol, symbol → name, name → symbol, or type them all in order.
  Questions can be random or in order (1, 2, 3, 4…)
- **Mnemonics & tips**: sentences for the first 20, group patterns, Latin symbols

No build step, no dependencies. Open `index.html` or visit the GitHub Pages site.
